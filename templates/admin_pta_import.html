从 PTA（拼题 A）一键导入题目

不用装 Python、不用传文件：在下面把 F12 复制的「整段 cURL」粘进来，点一下，后台自动抓题入库。

① 准备 PTA 登录凭据（只需做一次）

PTA 的登录令牌在 HttpOnly Cookie 里，浏览器书签的 document.cookie 读不到， 必须从 Network 抓「复制为 cURL」：

  1. 浏览器登录 pintia.cn，打开你的题目集 / 考试页。
  2. 按 F12 → Network（网络） 标签。
  3. 随便点一条 pintia.cn/api 开头的请求（例如 problem-status）。
  4. 右键该请求 → 复制 → 复制为 cURL（bash）。
  5. 把整段 cURL 粘到步骤②的「PTA 登录凭据（cURL）」框里即可 （脚本会自动从中抠出 Cookie、题目集 ID、考试 ID，无需手填）。

{{ icon('info', 15) }} 嫌 cURL 太长？也可以只复制请求里的 Cookie: 请求头那串，但整段 cURL 最省事（考试类题目集尤其需要里面的考试 ID）。
